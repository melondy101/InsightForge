## 1. 产品定位

**一句话**：本地优先的桌面反代写写作工作台 —— 你的知识库在你自己的文件夹里，AI 只递问题与证据，血肉由你亲手补。

织知不替你写完整文章，而是围绕「已有知识」做三件市面工具都不做的事：

1. **知识库主权** —— 知识库就是用户自己的本地文件夹：应用只读索引、索引库可全量重建，源文件永不被修改；不把笔记搬进任何云端。
2. **反代写陪练** —— 只在用户显式说「我卡住了」时出现；只问问题、指证据、点张力、给方向、拆微任务，三轮之后把笔还给作者，绝不输出成段正文。
3. **出站可审计** —— 每次 AI 调用先由本地生成最小出站包并明示「将发送 N 个片段」；BYOK 密钥存系统凭据库；调用留审计。完整目录、完整文件、本机路径永远不出门。

## 2. 目标用户

- **创作者 / 写作者**：本地散落着大量 `.md` / `.txt` 笔记、摘抄、旧文，写卡住时想要「提问与证据」，而不是代笔。
- **知识工作者**：需要把私有资料整理成可发布的成文，但拒绝把整个资料库上传到任何服务。
- **反代写理念认同者**：希望 AI 的输出被硬约束在「问题 / 证据 / 方向」的框架内的人。

## 3. 核心用户流程

```
添加来源目录 → 后台索引（启动补扫 / 文件监听 / 间隔校验）
        → 检索取证（关键词 → 证据卡）
        → 打开草稿（真实 .md 文件）→ 引用证据 → 写作补血肉
        →（卡住时）陪练三轮：问题 / 证据 / 张力 / 方向 / 微任务
        → 导出发布：通用 HTML（WordPress 等 CMS）/ 公众号剪贴板 HTML
```

## 4. 与旧版（Web ≤ 0.3.9）的关键差异

桌面版是**从零重写**：不迁移旧应用数据，不保留 Web 应用、服务端数据库或浏览器存储兼容层。

| 维度 | 旧 Web 版（≤ 0.3.9） | 桌面版（本 PRD） |
| --- | --- | --- |
| 形态 | Next.js Web 应用 + Tauri 静态导出壳 | Tauri 2 纯桌面应用（Rust 本地核心） |
| 数据 | Postgres / 浏览器 localStorage | SQLite（应用数据目录）+ 用户本地文件夹 |
| 知识入库 | 粘贴/上传碎片，自动归簇 | 只读索引本地文件夹（首版 `.md` / `.txt`） |
| 选题发现 | 空白勘探（本地启发式 / AI 发现） | 检索取证 + 陪练（首版不做选题发现） |
| 骨架 | AI 生成只读提纲，常驻三栏 | 陪练动作（directions 等），仅在「我卡住了」后出现 |
| 护栏 | 字数占比 / 展开次数 / 每日流入上限 | 陪练三轮上限 + 出站片段上限（AI 根本不写字） |
| 回流 | 成文回流知识库 | 无（知识库只读；未来可把成文目录加为来源） |
| AI 接入 | 服务端代转 / 前端直连 | Rust ai_gateway + 系统凭据库 |
| MCP / API 路由 / 环境变量 | 有 | 全部移除 |

旧版 PRD 第 13 节的全部「待确认事项」在本重写中随范围重划一并了结（导出格式定为两种、护栏由协议上限取代、快速采集 / 登录体系 / 数据删除等不再保留）。

## 5. 范围与非目标

### 5.1 首版范围

Windows 优先的纯桌面应用；最多约 10,000 个文件、2 GB 文本资料；知识库目录严格只读，草稿/成文目录单独授权为可写；AI 是可关闭的 BYOK 增强层。

### 5.2 明确不做（非目标）

- 不做 Web 版、服务端 API、Postgres、MCP 服务；不迁移旧数据。
- 不做 embedding / 向量检索 / 语义搜索；首版只有本地关键词检索。
- 不做后台守护进程；关闭即退出。
- 不做微信 API 直发、草稿箱同步、图片托管。
- 不做自定义 CSS、主题市场、复杂模板（首版一个固定主题 + 强调色）。
- 不做 Word 式 WYSIWYG 承诺；Markdown 是唯一真相。
- 不做知识库写回；本地图片不做 base64 内嵌。

## 6. 功能模块

### 6.1 来源管理

| 命令 | 说明 |
| --- | --- |
| `sources.add` | 授权一个本地根目录并命名；默认不跟随逃出根目录的 symlink。 |
| `sources.list / pause / remove` | 启停与移除；移除只删索引记录，不动源文件。 |
| `sources.sync` | 手动同步。 |

- 每个来源可配置忽略规则（ignore globs）与允许的扩展名（首版 `.md` / `.txt`）。
- 知识库目录对应用是**只读**的：任何写入路径在 Rust 侧被拒绝。

### 6.2 本地索引

- 一致性来源是**补扫**而不是 watcher：启动补扫、手动同步、5/15/30 分钟间隔校验负责最终一致；文件事件只负责尽快触发工作。
- 增量流程：验证授权根目录 → 遍历扩展名与 ignore 规则，记录稳定文件标识、规范路径、size、mtime、内容 hash → 仅对新增或 hash 改变的文件解析 → Markdown 优先按标题、其次按段落与长度窗口分块 → 单个 SQLite 事务内替换该文件的片段与 FTS 行。
- 删除的文件退出未来检索；已被草稿引用的片段保留**不可变引用快照**并标记「来源不可用」。
- 重命名优先按 file identity 识别，其次按内容 hash + 时间窗口，避免「删除再新增」。
- 索引进度通过事件通道推送，UI 可见；索引不阻塞交互。

### 6.3 本地检索

- SQLite FTS5：`bm25()` 排序、`highlight()` / `snippet()` 生成片段上下文。
- 中文实测 trigram tokenizer；两字符查询回退到受限线性扫描。
- 检索结果以**证据卡**呈现：片段文本 + 来源标题（无本机路径）+ 排名与上下文。

### 6.4 写作工作台

- 可调三栏：Markdown 编辑器为主栏，**正文宽度下限 35%**；证据架 / 检索在侧栏。
- 编辑器首版为 CodeMirror 6 Markdown source editor，通过装饰、侧栏卡片和预览提供富体验；富文本 AST 绝不成为文件真相。
- 编辑器藏在 `EditorAdapter` 适配层后，替换实现前必须先建立 Markdown round-trip 语料测试，杜绝悄悄改写用户文件。

### 6.5 草稿与冲突

| 命令 | 说明 |
| --- | --- |
| `drafts.open` | 打开授权输出目录中的真实 `.md` 文件，或新建。 |
| `drafts.save` | 原子保存：同目录临时文件写入 → flush → sync → 平台替换（Windows `ReplaceFileW`，Unix 同文件系统 rename）。 |
| `drafts.resolve_conflict` | 冲突处理。 |

- 打开时记录保存基线 `{file identity, content hash, mtime, size}`；每次保存先重读元数据，外部已变化则返回结构化 `Conflict`，用户查看 diff 后三选一：**保留本地 / 采用外部 / 另存为**，绝不静默覆盖。
- 只有替换成功后才更新数据库基线。
- 数据库只存草稿元数据（路径标识、基线、写作意图、布局）；正文永远在磁盘文件里。

### 6.6 证据架

- 检索命中的证据卡可固定在证据架上，并可引用进草稿。
- 引用写入 `draft_reference`：草稿位置 ↔ 片段 ID + **不可变引用快照** + 采用状态。
- 来源文件删除后，快照保留并标记「来源不可用」，成文不受影响。

### 6.7 陪练（Coach）

| 命令 | 说明 |
| --- | --- |
| `coach.start` | 用户显式点「我卡住了」后开始会话。 |
| `coach.respond / resume` | 三轮协议内交互；满足接续条件才可继续。 |
| `coach.mark_helpful` | 对本轮帮助度反馈。 |

- 三轮协议：会话最多三轮，结束即把笔还给作者；轮次记录在 `coach_session` / `coach_turn`。
- AI 响应必须解析为白名单动作：`question | evidence | tension | directions | micro_task`；疑似连续正文的输出**直接丢弃**并替换为本地安全提示。
- 陪练轮次在草稿发布后默认折叠，且**不进入检索**。

### 6.8 思考卡

- `thoughts.confirm / update`：作者确认「想法 ↔ 素材 ↔ 草稿位置」的关系，沉淀为 `thought_card`。
- 思考卡是作者资产，不随索引重建删除。

### 6.9 AI 设置与审计

- BYOK：OpenAI 兼容 API（base / model 可配），密钥存入系统凭据库（Windows Credential Manager；未来 macOS Keychain、Linux Secret Service）。
- AI 总开关：关闭后除 AI 外全功能可用。
- 每次远端调用前，Rust 生成不可变 `EgressBundle`：当前选区或光标前后段落、标题/大纲、已引用素材、**最多三条**检索片段、无本机路径的来源标题。UI 明示「将发送 N 个片段」，只有该 bundle 可进入 HTTP client。
- `ai_call_audit` 记录模型、时间、发送片段数量/ID、状态；不重复保存敏感全文。

### 6.10 平台导出

| 目标 | 产物 | 用途 |
| --- | --- | --- |
| `generic-html` | 语义化、已消毒、含阅读排版样式的完整 HTML 文件 | WordPress 及其他 CMS 粘贴或导入 |
| `wechat-clipboard-html` | 标签/属性受限、样式内联的 HTML 片段，同时写入 `text/html` 与 `text/plain` 剪贴板 | 手动粘贴到微信公众号编辑器 |

- Markdown 是唯一草稿真相；导出是派生物，不反向修改草稿。
- 排版采用「一个 Markdown 真相、两套输出皮肤」：固定 `Clean Reading` 主题（16px 正文、1.8 行距、浅色引用块、移动端安全），首版仅开放一个强调色。
- 图片只允许可公开访问的远程 `https` URL；不可访问的图片**阻断导出并明确提示**，不产生表面成功实际丢图的内容。
- Markdown 内嵌 HTML 默认禁用；不安全协议的链接降级为纯文本。

### 6.11 打包与更新

- Windows 首发产出**签名** NSIS 或 MSI 安装包；Tauri updater 强制校验签名，可用静态 JSON / GitHub Releases，不自建业务服务器。
- 首发使用系统 WebView2 + bootstrapper；为确有离线安装需求的组织另产 offline installer。

## 7. 非功能性需求

| 目标 | 指标 |
| --- | --- |
| 规模 | ≤ 10,000 文件 / 2 GB 文本下流畅检索与增量索引。 |
| 一致性 | watcher 仅触发；启动补扫 + 手动同步 + 间隔校验保证最终一致（watcher 对网络盘/超大目录可能漏事件）。 |
| 可靠性 | 原子保存 + 断电 / 进程崩溃 / 锁占用 / 杀软干扰的恢复用例通过。 |
| 响应性 | 扫描、解析、hash、写入运行在 blocking executor，带显式 cancellation token，不阻塞 UI。 |
| 不驻留 | 关闭即退出，无后台守护进程。 |
| 离线 | 除 AI 出站外全部功能离线可用。 |
| 可重建 | 索引库（含 FTS 表、扫描游标、缓存）可全量重建；引用快照、思考卡、求助摘要、保存基线不随重建删除。 |
| i18n | 用户可见文案一律走 `react-i18next`（zh-CN / en-US，默认中文），不硬编码。 |

## 8. 安全与隐私边界

| 维度 | 约束 |
| --- | --- |
| 最小权限 | 只注册业务命令；renderer 不获得任意文件系统、任意网络、任意 SQL 权限。 |
| 文件边界 | 知识库目录只读、草稿目录可写、symlink 不越界；动态目录授权的领域规则在 Rust 业务服务内执行，不靠通用 FS scope。 |
| AI 出站 | 仅 `EgressBundle` 可进入 HTTP client；无完整目录、无完整文件、无本机路径。 |
| AI 输入 | 响应动作白名单校验，疑似连续正文丢弃。 |
| 密钥 | BYOK 存 OS 凭据库；数据库与前端不可见明文。 |
| 隐私承诺 | 不采集、不上报；除用户显式配置的 AI 出站外无任何网络行为。 |

## 9. 界面视图

| 视图 | 职责 |
| --- | --- |
| 工作台 | 主界面：可调三栏（编辑器居中 + 证据架/检索侧栏）；陪练仅在「我卡住了」后出现。 |
| 来源管理 | 添加 / 暂停 / 移除 / 同步目录；忽略规则；索引状态与进度。 |
| 设置 | AI（BYOK、模型、总开关）、同步间隔、忽略规则、语言（zh-CN / en-US）。 |

草稿通过工作台从输出目录打开或新建；不设独立「成文库」视图（草稿即成文）。

## 10. 技术栈

| 层 | 技术 |
| --- | --- |
| 桌面壳 | Tauri 2（系统 WebView2 + bootstrapper） |
| 前端 | React + TypeScript + Vite（无 Next.js / SSR / API routes） |
| 编辑器 | CodeMirror 6（`EditorAdapter` 适配层） |
| 本地核心 | Rust：sources / indexer / search / drafts / coaching / ai_gateway / secrets / repository |
| 数据 | SQLite + FTS5（WAL、单写队列、≥ 3.51.3 含 2026 WAL-reset 修复） |
| 密钥 | OS 凭据库（Windows Credential Manager） |
| 导出 | `remark-parse → remark-gfm → remark-rehype → rehype-stringify`（含 sanitize） |
| 打包/更新 | 签名 NSIS / MSI + Tauri updater（强制签名） |
| 测试 | Rust 单元/属性测试 · 临时目录 + SQLite 集成测试 · Windows 桌面 E2E |
| i18n | react-i18next（zh-CN / en-US） |

架构细节见 [ARCHITECTURE.md](./ARCHITECTURE.md)。

## 11. 配置与密钥

无环境变量、无 `.env`：所有配置在应用设置内完成，密钥入系统凭据库。首版不要求联网即可完成除 AI 外的全部流程。
