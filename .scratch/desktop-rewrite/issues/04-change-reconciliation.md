# 04 — 文件变更收敛与索引维护

**What to build:** 来源目录里的新增、修改、删除、重命名最终都会反映到检索结果——无论文件监听是否漏事件。用户可手动触发同步、在设置中选择 5/15/30 分钟间隔校验，并可触发重建索引；删除的文件退出检索。

**Blocked by:** 02 — 添加来源并完成首次补扫索引；03 — 中文关键词检索与证据卡

**Status:** ready-for-agent

- [ ] 文件事件只负责尽快触发工作；新增 / 修改 / 删除 / 重命名后检索结果收敛正确
- [ ] 重命名优先按 file identity 识别，其次按内容 hash + 时间窗口，不产生「删除再新增」
- [ ] watch 漏事件场景由启动补扫 / 手动同步 / 间隔校验收敛（临时目录 + SQLite 集成测试覆盖）
- [ ] 删除的文件退出未来检索；被引用片段的处理衔接 07 号票据的快照行为
- [ ] 重建索引（清空派生数据后全量补扫）后检索结果一致
- [ ] 间隔校验间隔（5/15/30 分钟）可在设置中调整
