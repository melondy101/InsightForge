# 03 — 中文关键词检索与证据卡

**What to build:** 用户输入中文关键词，即得到按相关度排序的证据卡：片段文本、来源标题（不含本机路径）与片段上下文；两字词也能出结果。10k 文件规模下检索流畅（M0 第 2 项验证折叠于此）。
