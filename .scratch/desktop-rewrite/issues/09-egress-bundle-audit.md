# 09 — 出站包 EgressBundle 与调用审计

**What to build:** 每次远端 AI 调用前，应用由 Rust 生成本地不可变出站包，并在 UI 明示「将发送 N 个片段」——载荷恰为当前选区或光标前后段落、标题 / 大纲、已引用素材、至多三条检索命中片段与无本机路径的来源标题。调用留审计，完整目录、完整文件、本机路径永不出站。

**Blocked by:** 06 — 草稿打开、原子保存与冲突三选一；07 — 证据架与不可变引用快照；08 — BYOK 凭据库与 AI 总开关

**Status:** ready-for-agent

- [ ] EgressBundle 由 Rust 生成且不可变；只有它能进入 HTTP client（以假 HTTP 实现在 seam 后验证）
- [ ] UI 在调用前明示「将发送 N 个片段」，N 与实际载荷一致
- [ ] 载荷不含本机路径，检索命中片段 ≤ 3 条
- [ ] `ai_call_audit` 记录模型、时间、发送片段数量 / ID、状态；不重复保存敏感全文
