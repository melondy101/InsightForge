# 02 — 添加来源并完成首次补扫索引

**What to build:** 用户把一个本地文件夹添加为命名来源后，应用在后台扫描其中的 `.md` / `.txt` 文件，完成 hash 与分块并写入片段与 FTS 索引，索引进度实时可见；来源可暂停、恢复、移除（移除只清理索引记录，绝不动源文件）。知识库目录对应用严格只读。

**Blocked by:** 01 — 桌面工作区骨架与 SQLite 地基

**Status:** ready-for-agent

- [ ] 添加来源（目录选择 + 命名 + 默认忽略规则）后补扫完成，进度经事件通道驱动 UI 展示
- [ ] Markdown 优先按标题、其次按段落与长度窗口分块；单个 SQLite 事务内替换该文件的片段与 FTS 行
- [ ] 暂停 / 恢复 / 移除来源可用；移除后源文件原样保留
- [ ] 对知识库目录的写入路径在 Rust 侧被拒绝；symlink 逃逸与 path traversal 用例全部拒绝；源文件内容 hash 前后不变（M0 第 4 项验证折叠于此）
- [ ] 阻塞型扫描 / 解析 / hash / 写入运行在专门 executor 且带取消令牌，索引期间 UI 不卡顿
